# Simple TypeScript App

This is a simple TypeScript application that displays a welcome page. The project includes a basic HTML structure, CSS for styling, and TypeScript for functionality.

## Project Structure

```
simple-ts-app
├── src
│   ├── index.html      # HTML structure of the welcome page
│   ├── styles.css      # CSS styles for the welcome page
│   └── app.ts          # TypeScript file with application logic
├── package.json        # npm configuration file
├── tsconfig.json       # TypeScript configuration file
└── README.md           # Project documentation
```

## Getting Started

To set up and run the application, follow these steps:

1. **Clone the repository** (if applicable):
   ```bash
   git clone <repository-url>
   cd simple-ts-app
   ```

2. **Install dependencies**:
   If you have any dependencies listed in `package.json`, run:
   ```bash
   npm install
   ```

3. **Compile TypeScript**:
   To compile the TypeScript files, run:
   ```bash
   npx tsc
   ```

4. **Open the HTML file**:
   Open `src/index.html` in your web browser to view the welcome page.

## Features

- A simple welcome message displayed on the page.
- Basic styling to enhance the visual appearance.
- TypeScript for better development experience and type safety.
